{% comment %} Feedback for download controls. Browsers do not open a save dialog by default -- the file goes straight to the download folder -- so clicking a download button produces no visible change in the page. On the large region downloads nothing arrives for up to a minute either, because the file streams. Between the two, a working download is indistinguishable from a broken button. Attach by adding class="js-download" to any button or link that starts one. {% endcomment %}
